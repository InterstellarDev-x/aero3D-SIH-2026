Aero3D

Single-image → elevation → 3D flythrough prototype for ISRO's SIH 2026 Disaster Management problem statement. Judged on DSM accuracy (50%) and visualization quality (50%).

Pipeline

optical ingest → mono-depth v2.1 (sim) → SRTM-anchored calibration (sim) → 130k-tri Three.js mesh → flythrough

Disclaimer

All elevations, accuracies and land-cover labels on this demo are simulated — not survey-grade. Built for evaluation, not field use.

Attribution

3D engine: Three.js · elevation anchor: simulated SRTM-30 m fit · built with Vite + TypeScript. All demo scenes are procedurally generated in-browser — no real sensor data is used.

Credits

Prototype built for SIH 2026 · ISRO (Disaster Management problem statement). Content is illustrative and evaluation-only — not for operational or field use.
